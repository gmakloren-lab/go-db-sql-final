# Go Database SQL Project

Учебный проект на Go для работы с базой данных SQLite.

Проект реализует сервис управления посылками: регистрацию, изменение адреса, изменение статуса, получение списка посылок клиента и удаление посылок с учетом бизнес-правил.

Проект выполнен в рамках обучения Go Backend Developer.

---

## О проекте

Приложение моделирует простую систему отслеживания посылок.

Каждая посылка содержит:

- номер посылки;
- идентификатор клиента;
- статус;
- адрес доставки;
- дату создания.

Поддерживаемые статусы:

```
registered → sent → delivered
```

Изменение состояния происходит последовательно.

---

## Возможности

Реализованы следующие операции:

### Регистрация посылки

Создание новой посылки:

- назначается клиент;
- устанавливается адрес;
- автоматически создается дата регистрации;
- начальный статус — `registered`.

---

### Получение посылок клиента

Можно получить список всех посылок определенного клиента.

---

### Изменение статуса

Поддерживается переход:

```
registered → sent
sent → delivered
```

После доставки изменить статус нельзя.

---

### Изменение адреса

Адрес можно изменить только если посылка находится в статусе:

```
registered
```

Для отправленных и доставленных посылок изменение адреса запрещено.

---

### Удаление посылки

Удаление разрешено только для зарегистрированных посылок.

После отправки или доставки удалить посылку невозможно.

## Архитектура

Проект разделен на несколько частей:

### ParcelService

Сервисный слой.

Отвечает за бизнес-логику:

- регистрацию посылок;
- изменение статусов;
- изменение адресов;
- вывод информации.

---

### ParcelStore

Слой работы с базой данных.

Отвечает за:

- добавление записей;
- получение данных;
- обновление;
- удаление.

Используется стандартный пакет:

```go
database/sql
```

---

## База данных

Используется SQLite.

Подключение:

```go
sql.Open("sqlite", "tracker.db")
```

Таблица `parcel` хранит информацию о посылках:

| Поле | Описание |
|---|---|
| number | номер посылки |
| client | идентификатор клиента |
| status | текущий статус |
| address | адрес доставки |
| created_at | время создания |

## Запуск проекта
